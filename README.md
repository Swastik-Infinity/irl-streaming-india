# Field Notes IRL — India

A static, framework-free blog about IRL streaming in India.

## Run locally
Open `index.html` in a browser. All pages use relative paths and need no build step.

## Deploy to Vercel
1. Upload every file in this folder to the root of a GitHub repository.
2. In Vercel, import that repository and deploy as a static site. No framework or build command is required.
3. Once the production domain is known, replace every `https://YOUR-SITE.vercel.app` placeholder in all HTML files, `sitemap.xml`, and `robots.txt` with the exact production origin. Keep the trailing slash on the homepage canonical.
4. Commit and push the changes; Vercel redeploys automatically.
5. Open Google Search Console, add the production domain or URL-prefix property, complete verification, then submit `/sitemap.xml`. Use URL Inspection for the homepage and request indexing.

## Images
`post-1.jpg` through `post-10.jpg` are original locally generated editorial cover illustrations. They are included in this folder and referenced with relative paths.

## Notes
- The site does not use analytics, cookies, third-party fonts, external image APIs, or JavaScript frameworks.
- Search indexing and rankings are not guaranteed.
- Verify platform rules, venue permissions, and current legal requirements before streaming.
